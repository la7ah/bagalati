# بقالتي الفلانيه

تطبيق عربي بسيط وسريع لإدارة المخزون والمنتجات وتسجيل المبيعات.

## المميزات
- إضافة المنتجات وتحديد أسعارها وكمياتها
- خصم الكمية تلقائيًا عند تسجيل البيع
- تنبيهات مرئية للمنتجات القليلة في المخزون
- البحث عن المنتجات
- حفظ البيانات محليًا في المتصفح
- تصدير المبيعات إلى ملف CSV

لا يتطلب التطبيق خادمًا أو أي تثبيت؛ افتح `index.html` أو فعّل GitHub Pages من إعدادات المستودع.
